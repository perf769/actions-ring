# Icon collections

Actions Ring includes Lucide 1.43.0 (2,077 icons) and Simple Icons 16.30.0 (3,459 icons). The bundled SVGs are displayed as scalable monochrome icons. The OpenAI mark is sourced from theSVG.

- Lucide: https://github.com/lucide-icons/lucide — ISC; Feather-derived icons are MIT. See `LUCIDE-LICENSE.txt`.
- Simple Icons: https://github.com/simple-icons/simple-icons — CC0 1.0 for the collection. See `SIMPLE-ICONS-LICENSE.txt`, `SIMPLE-ICONS-DISCLAIMER.md`, and `simple-icons-attribution.json` for original sources, brand guidelines and individual icon licenses.
- OpenAI mark: https://github.com/glincker/thesvg/blob/main/public/icons/openai/default.svg — https://github.com/glincker/thesvg/blob/main/LEGAL.md.
