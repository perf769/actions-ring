# Actions Ring для macOS

Контекстное кольцо действий для Mac с Apple Silicon и macOS Sonoma 14 или новее.

## Установка

1. Распакуйте `ActionsRing-macOS-AppleSilicon.zip` и перенесите **Actions Ring.app** в **Программы**.
2. Откройте приложение. Сборка не заверена Apple: если macOS блокирует первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** для Actions Ring. Разрешайте запуск только пакета из [официального репозитория](https://github.com/perf769/actions-ring). На управляемом Mac это может ограничиваться политикой организации.
3. В настройках Actions Ring предоставьте **Универсальный доступ** и **Мониторинг ввода**. Эти разрешения нужны для глобального вызова кольца и выполнения сочетаний клавиш. Нажатия не записываются и не отправляются в сеть.

Платный аккаунт Apple Developer пользователю не нужен. Инструкция первого запуска также доступна [на сайте Apple](https://support.apple.com/en-gb/102445).

## Управление

По умолчанию: удерживайте **Control + Option** и прокрутите вверх на трекпаде. В разделе **Вызов кольца** можно выбрать другое направление, клавишу, сочетание или кнопку мыши. Режим удержания закрывает кольцо при отпускании назначенной клавиши, кнопки или модификаторов жеста.

Наведите указатель на пузырь с подменю, чтобы раскрыть дополнительные действия. По клику родительский пузырь может выполнять собственное действие. Крестик и Escape закрывают кольцо. После закрытия окна настроек приложение остаётся в строке меню.

## Возможности

- Пользовательские профили и отдельные кольца для приложений по их bundle identifier.
- Поиск по категориям действий, собственные сочетания клавиш, приложения, сайты, файлы, папки и текст.
- Mission Control, окна приложения, рабочие столы, снимки экрана, Spotlight, блокировка и громкость.
- Готовые команды Photoshop и браузеров.
- Вложенные подменю, иконки SF Symbols, иконки приложений и собственные изображения.
- Светлая и тёмная схемы интерфейса, темы кольца и отдельные цвета пузырей.
- Масштаб кольца, плавные анимации, уменьшенное движение и запуск при входе.
- Импорт и экспорт настроек; автоматическая резервная копия предыдущего сохранения.

Системные команды используют стандартные сочетания macOS. Если они изменены в системных настройках, назначьте соответствующие сочетания в Actions Ring.

Системные трёх- и четырёхпальцевые жесты остаются под управлением macOS. Actions Ring использует сочетание модификаторов с прокруткой; оно не определяет количество пальцев и также доступно с совместимой мышью. Готовые действия Mission Control и переключения рабочих столов дают доступ к тем же системным функциям из кольца.

Настройки хранятся в `~/Library/Application Support/ActionsRing/settings-macos.json`. Конфигурация Windows хранится отдельно: произвольные Windows-сочетания и EXE-пути не преобразуются в команды Mac автоматически.

## Сборка

На Mac с Apple Silicon и установленными инструментами Xcode:

```sh
bash macOS/build.sh
```

Скрипт выполняет тесты, создаёт arm64-приложение с локальной подписью ad-hoc, проверяет пакет и сохраняет ZIP в `dist/macos`. Сертификат Developer ID и нотариальное заверение Apple не используются.
